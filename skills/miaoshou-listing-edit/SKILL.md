# 妙手公用采集箱商品优化

以用户指定的采集箱、商品、字段和目标站点为准。Shopee 马来站默认使用自然英文，进度和交付说明用中文。用户只要文案或建议时，交付可复制文本。单独翻译商品规格时逐行给纯文本，缺失单位原样保留，有疑点时另行指出。用户要求优化当前商品或在后台修改时，直接填写编辑器，默认将未保存的改动留在当前页面并汇报。公用采集箱、平台采集箱与卖家中心是不同位置，认领、同步和发布需要用户另行授权。

## 1. 定位商品并记录原始数据

1. 优先使用可用的妙手专用连接器。需要操作网页时，使用当前会话支持的浏览器或 Computer Use 工具，接续已登录的妙手页面。确认路径为「产品 → 公用采集箱」，并查看「全部／未认领／已认领」的当前页签。
2. 可按标题或货源 ID 缩小范围。货源 ID 可能对应多条采集记录，最终用采集箱 ID 锁定该行的「编辑」。用户未提供采集箱 ID 时，从列表核对标题、图片和货源，确定唯一记录后记下 ID。候选仍无法区分时，给出有差异的候选请用户选择。
3. 打开后核对编辑器内当前选中的商品。读取原始标题、目标平台对应的描述、产品属性和全部销售规格。逐行记下 SKU 原名和对照字段，例如图、货源价格、库存、平台 SKU 编码、重量和尺寸。虚拟列表或内部滚动区只显示部分行时，继续滚动或展开，直到覆盖实际 SKU 数量。需要确认事实时，优先看该商品的规格、对应商品图和可访问的货源资料。

## 2. 优化标题、描述与 SKU 规格

- **标题**。优先写买家会搜索的品类词，再补已核实的用途、结构或选购差异。删去工厂口号、重复同义词和堆砌关键词。配件、把手或抽屉仅部分规格具备时，用选项措辞或在描述中按款说明。按当前编辑器可见长度限制检查。
- **描述**。Shopee 在公用采集箱用「基本信息 → 简易描述」。按「推荐语＋规格」排版，交付可直接粘贴的纯文本。
  - **推荐语**放在开头，写一小段自然的买家文案。交代商品适合什么场景，选一两个已核实的实用卖点，说明买家如何使用或能获得什么便利。
  - **QiQi's Life Picks 店铺风格**。为该店铺撰写或整体优化简易描述时，默认先用一两句亲切的英文问候和过渡引出商品，例如 `✨ Hello from QiQi's Life Picks! (｡•ᴗ•｡)`，下一句结合商品用途自然衔接。推荐语可按使用场景分成短行，用贴合场景的表情符号引导阅读，并在问候或其中一行加少量颜文字，例如 `( •̀ᴗ•́ )و`。店铺名拼写使用 `QiQi's Life Picks`。用户指定其他语气或只改局部时，按指定范围和风格处理。
  - **规格**另起一段。英文使用 `Specifications` 作小标题，每行列一项已核实的信息，如材质、可选颜色或款式、尺寸、套装数量、包装内容。不同 SKU 的配置有差异时分款写明。件数与包装清单要一致，配件是否计入总件数须核实后再拆分。颜色以销售属性为准，只能看到原描述时在交付说明里标明核对状态。
  - 尺寸须确认单位和测量对象，物流包装尺寸不可当作商品尺寸。省略未经核实的温度上限、容量、认证和性能承诺。详细描述用于页面注明的其他平台，按目标平台或用户要求编辑并保留原有图片。
- **SKU**。在「销售属性／SKU 信息」改规格组名和选项名，保留一对一对应。纯颜色用 Color 或 Colour，混合结构、颜色和套装可用 Style。选项简短且唯一，能看出颜色、单品或套装，按当前字段限制检查字符。仅改显示名称时，使用原选项的编辑控件，保留规格轴、选项数量、原有 SKU 行及其图片、货源价、库存、编码和物流数据。「平台 SKU」是编码字段，用户明确要生成或重编编码时再按要求变更。

### 波浪款化妆品收纳盒示例

- 标题示例为「Wave Design Makeup & Skincare Organiser Box - Carry Case, 2-Drawer Unit or Set」。
- 推荐语可写日常化妆品与护肤品收纳。规格段分行列出透明手提盒、双抽屉单品和组合套装，注明套装包含一个透明手提盒和所选颜色的双抽屉单元。只有该商品资料确认为 PET 时才写 PET。
- 规格组用 Style。原顺序逐项映射为 Clear Carry Case、White Drawers Only、Cream Drawers Only、Black Drawers Only、White Drawer Set、Black Drawer Set、Cream Drawer Set。示例的套装构成与规格名称仅适用于匹配该结构的商品。

## 3. 填写并汇报

1. 优先用当前页面的控件定位和编辑。切换窗口、滚动、打开弹窗、页面重绘或动作失败后，重新获取页面状态。页面控件无法定位而需按坐标点击时，取当前目标窗口的新截图，并在点击后核对页面或焦点。窗口位置或大小发生变化时，重新截图定位。
2. 填写后在当前编辑器核对改动字段。SKU 改名后检查列表中的名称、数量和原始数据对应关系。若出现行重建、顺序变化或数据清空，按行标识、图片与原始记录重新匹配。无法恢复时说明具体问题。
3. 默认核对后立即汇报，说明商品 ID、改动概况及「已填写，未保存」。保留当前编辑器及表单内容，跳过「保存修改」和保存后回读。使用浏览器工具时，将编辑标签页标记为待交接，方便用户接手。
4. 仅在用户明确要求保存时点击「保存修改」。确认系统提示成功后，重新打开同一采集箱 ID，核对改过的字段、描述换行及 SKU 的对应关系。列表疑似缓存时先刷新。保存失败时按可见反馈检查字段，修正后在确认仍是同一条未保存记录时重试。汇报实际保存状态及尚未核实的事项。
