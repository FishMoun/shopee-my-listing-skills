# 后台取数

## 中国卖家中心

- 优先使用当前已登录的中国卖家中心。按页面或当前浏览器选中店铺确认马来西亚、新加坡等站点以及 SLS、FBS 或 3PF 履约。本站历史入口为 [店铺商品](https://seller.shopee.cn/portal/product/list/all)，也可通过当前菜单进入。使用前核对页面所选店铺。
- 从 [全球商品](https://seller.shopee.cn/portal/product/mtsku/list) 对照待发布、未发布或待编辑商品。记全球商品 ID、全球 SKU、规格名、图片、标题、描述、属性、材质、包装规格、重量和来源，核对是否已映射到 MY 店铺。可在 MY 发布预览取站点价、折前价和运费预览，记录预览状态。未发布商品的拟售价不记作在售价。若已有 MY 商品，打开店铺列表的一条确定记录，或按已核实的店铺商品 ID 打开 `/portal/product/<商品ID>`。切换全球和店铺商品时用 SKU 或确切规格匹配，别按相似标题配价。
- 展开每个商品的【查看更多】或全部规格，检查列表分页、规格行数、库存及是否停用。每行记录税前原价、当前有效实价、活动开始和结束、售价复核时间、含包装重量。区分税前和买家前台含税价。售罄规格保留折前标价，实际可购售价留空。用折前价格试算时标记售罄试算。显示模板生成成功只表示已生成，只有文件确实取得并解析后才能作为数据源。
- 核实际活动、价格历史和自动调价时，查看当前店铺的营销中心、价格编辑限制和相关同步来源。进入商品详情、指标页或预览时保留原始值。页面不可访问时用用户提供的截图或导出，说明缺什么；别猜后台显示。

## 货源及账单

- [妙手公用采集箱](https://erp.91miaoshou.com/common_collect_box/items?tabPaneName=claimed) 按采集箱记录、供货链接和规格交叉确认。同一个货源 ID 可能出现多行，虚拟列表也可能隐藏其他行。先识别唯一记录，再读取编辑页的规格、供货价、采购数量门槛和 SKU，不保存。采购价以确认报价、实际采购单或同规格可下单单价为准。采集价或阶梯最低价单列为未确认。来源图可能说明属性，图片使用权需单独核对。
- 可只读查项目内「虾皮马来站商品与定价台账.xlsx」 的「商品 SKU 台账」和「定价参数」。先确认文件和列还存在。用户确认的 SKU 运费、有效凭证和后台账单优先。旧台账与现价冲突时保留差异，别直接把旧参数写回后台。若要更新表，保留原生表、样式和其他公式。
- 费用以同站点、同履约模式、同类目、同活动资格的【我的收入 → 收入详情】为已发生订单证据。未发布商品可拿同类已完结单验证各费基数，再按生效通知估算。核实新店免佣资格、截止日和额度，支持“未证实”状态。不读取或输出审查无关的订单个人信息。
- 输出关键字段的来源和状态，例如后台实值、供应商确认、官方规则估算、计划价、历史快照、缺失。只读取必要 SKUs。会话失效时使用已有导出或截图做可完成部分。
