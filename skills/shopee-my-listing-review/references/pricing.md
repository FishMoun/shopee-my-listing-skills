# 总成本与利润

## 统一口径

以 MYR、单订单为默认，逐个 SKU 先算一件一单。多件或多规格订单单独试算，按实际分摊规则处理包裹费用和固定费用，分摊额合计应等于订单费用。保留每个汇率、费率与报价的来源、生效日和方向。CNY 成本乘 MYR/CNY，马币原值不再换算。

- 收入 = 商品标价扣除**实际由卖家承担且尚未扣除**的商品折扣与券，加可确认的已入账平台补贴及其他卖家应收。买家运费、税费和平台券安排按真实结算拆分。服务费基数中的买家运费与卖家销售收入分开。使用后台已折后的卖家应收时不再次扣同一优惠。
- 总成本 = 采购 + 国内运费 + 云仓/贴单/包材 + 卖家应承担的 SLS + 佣金 + 交易手续费 + 基础设施费 + 适用活动、技术、分期等费用 + 卖家承担税费 + 广告/售后预留 + 汇兑/提现费用和其他适用成本。卖家券已冲减收入时不重复计成本。固定费按订单或规则摊分。采用净结算倒推时，要加回可核实且已扣的平台费用形成同口径收入，并将相同项目计入总成本一次。明细不足时可算预计现金贡献，但不能冒充完整总成本利润率。
- 利润 = 收入 − 总成本。**总成本利润率 = 利润 ÷ 总成本**。销售利润率 = 利润 ÷ 收入，可作为另列。分母为 0 时显示不适用。按订单实际科目舍入，规则未知用 MYR 分项四舍五入并标记估算。
- 对照 [费率与收费基数](https://shopee.cn/edu/article/25770)、[基础设施费](https://shopee.cn/edu/article/25798)、[SLS 定价模拟器](https://solutions.shopee.cn/sellers/pricing-simulator/)、[藏价与运费](https://shopee.cn/edu/article/5091)、[高价值商品税](https://shopee.cn/edu/article/19945)。不同费项分别确认基数、税口径、免佣与服务开通状态。实际包装重量、地区、渠道、货类和最新费率完整时才计算 SLS，不拿买家邮费代替卖家藏价，也不因售价公式已加藏价就漏记真实履约成本。
- 缺少关键成本或费率时优先获取来源。仍缺时明确按参数或区间试算，列缺项及影响，避免空值算作 0。免佣未核实时分别试算普通费率和已明确假设的免佣场景；利润结果和是否满足活动资格独立。

## 可复算脚本

从技能目录运行 `python scripts/calculate_profit.py scenario.json`。参数按订单输入一个 JSON，金额、费率推荐使用字符串。先把相同费用归在同一个科目，确认正负和费用承担。脚本只做算术，输入的收入为已经过卖家优惠调整的**结算前卖家收入**。费率用小数，0.05 表示 5%。使用实扣费用时放入固定金额明细，预估的百分比费用传实际费基。脚本不内置 Shopee 费率和完整性判定。

```json
{
  "revenue_myr": "15.90",
  "myr_per_cny": "0.60",
  "costs": [
    {"name": "采购", "amount": "8.00", "currency": "CNY"},
    {"name": "头程", "amount": "2.00", "currency": "CNY"},
    {"name": "卖家SLS", "amount": "3.00", "currency": "MYR"},
    {"name": "其他固定平台费", "amount": "0.54", "currency": "MYR"}
  ],
  "fees": [
    {"name": "示例佣金", "base_myr": "15.90", "rate": "0.10"},
    {"name": "示例交易费", "base_myr": "20.80", "rate": "0.03"}
  ]
}
```
示例结果总成本 RM11.75、利润 RM4.15、总成本利润率 35.32%。各费用纯为示例。
