# 马来站合规

## 查证顺序

先核商品结构、材料、用途、包装、品牌和营销主张，再查适用站点与卖家类型、最新规则、生效日期及附录。学习中心首次只返回空架时，用浏览器渲染后查正文和附件。查不到关键条款或证书时标“待核验”，按商品说明列出需要补充的具体证据。

- 售卖和进口。对照 [Shopee 禁售商品按站点索引](https://shopee.cn/edu/article/4506)、[跨境禁止和限制商品政策](https://shopee.cn/policy/27/176)、[马来西亚 Shopee 卖家学习中心](https://seller.shopee.com.my/edu/) 和相关马来西亚主管机构规则。无对应条目时仍要检查类目要求和适用认证。电池、电器、无线、儿童用品、食品接触、保健或化妆品按实际品类核应用规则，不按产品英文名猜证书要求。普通家居用品有“食品级”“耐热”“抗菌”“指定承重”等声明时核具体型号、证明与试验条件。
- 运输。对照 [SLS 禁运](https://shopee.cn/edu/article/25237) 和 [尖锐易碎物包装](https://shopee.cn/edu/article/26569)。材料、刀刃、电池、液体、粉末、磁性、重量体积按真实包裹和选定渠道判断。允许刊登并不代表可走选定物流渠道；核可用渠道后才能做履约和费率结论。
- 刊登与权利。查 [上架规范](https://shopee.cn/edu/article/4436)、[禁止刊登](https://shopee.cn/edu/article/4505)、[商品信息违规](https://shopee.cn/edu/article/16626)、[侵权及假冒商品](https://shopee.cn/edu/article/4515)。检查资质、来源图授权、文案与实物、标题/主图/变体/价格一致、最低价 SKU 与主展示主体、重复刊登、同一 ID 换品、站外导流、库存和预售是否真实。商品图、水印、视频、描述和包装都纳入审查。英文或马来语属于本地化建议，除非有适用的强制规则。
- 价格与促销。查 [我的折扣活动](https://shopee.cn/edu/article/4770) 和 [马来站误导折扣指引](https://seller.shopee.com.my/edu/article/1553/misleading-discount-prohibited-listing-)。已核实的中国跨境问答区分新上架保持原价 7 天后设折扣与改价后等 7 天才设折扣优惠券，执行前重核适用活动、最新规则与后台报错。明确正常定价、活动能否创建及已发出的违规通知三件事。已正式限权按后台通知处理，不能推定 7 天自动解除，也不能把复制商品或换发券当作绕过限制的办法。
- 分类判定。明确禁售、违禁运输且所选方案无可用合法渠道、侵权或其他明确禁止行为，标“不建议上架”并写对应事实。缺授权、证书、材质或无法核验规则时标“待核验”。文案/图片/规格有可纠正违规时标“整改后复审”，给具体修改项。平台审核结果以平台为准。

示例：硅胶沥水篮主图宣称“食品级、耐热 230°C”，供应商只有无型号的材质口头说明。按规格要求补充材质和适用证明，或删除未经验证的声明后复审。若食品接触情形的具体法规适用仍未知，保留待核验项。已有商品若活动前涨价，把促销资格单列，不能用账算得过来替代资格确认。
