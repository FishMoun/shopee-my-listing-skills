# 模板字段与复算方法

适用于「零售价计算器」中与以下单元格和公式一致的版本。模板发生修改时以当前表头和公式复核后执行。

- `B15:B17` 分别是目标总成本利润率、促销降幅、MYR/CNY 汇率。
- `B18:B20` 是人民币采购、国内运费与货代费。使用「全球商品价格」时将逐 SKU 的人民币全球价代入 `B18`。
- `B21:B23` 是 RM 卖家藏价及两项其他 RM 固定费用。按表头和本次商品核实各项。
- `E5:E10` 是按折后价计的费率或损耗，合计参见 `E11`。有免佣填 0 的场景时按本次模板与资格使用，其他费用分别核实。

用十进制金额复算时，设固定成本 `F = SUM(B18:B20) × B17 + SUM(B21:B23)`，目标为 `p`，折扣降幅为 `d`，费率合计为 `r`。

1. 验证 `F > 0`、`0 ≤ d < 1`、`1 − (1 + p) × r > 0`，必填输入齐全，汇率大于 0。经确认无该费用时才填 0。
2. 目标折后价为 `ROUNDUP(F × (1 + p) / (1 − (1 + p) × r), 2)`。模板建议折前价再做 `ROUNDUP(目标折后价 / (1 − d), 2)`。两次向上取分与实际模板一致。
3. 实际用于验算的折后价为 `ROUND(建议折前价 × (1 − d), 2)`。总成本为 `F + 实际折后价 × r`，利润为实际折后价减总成本，成本利润率为利润除以总成本。若平台预览或用户指定了其他逐项舍入、优惠或不同收费基数，按该口径再验算并指出差异。利润目标未达时按有效售价步长重新检查。

在工作簿复算时使用临时副本或内存计算。模板、平台费率和历史售价均按当次取值读取。
