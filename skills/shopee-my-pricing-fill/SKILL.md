# Shopee 马来站按模板定价与填价

1. 找到用户指定的项目定价工作簿。常用文件是项目根目录的「虾皮马来站建议零售价计算器.xlsx」，读取「零售价计算器」参数和公式。有效输入以本次用户指令、当前商品和当前模板为准。切换到下一款时重新读取模板与后台取值。
2. 确认马来站店铺、商品和履约渠道。展开全部变体或滚动完整列表，按 SKU ID 或完整规格组合、币种和字段建立一一对应。此工作流按用户指定口径将人民币「全球商品价格」作为货源成本。读取当前商品在马来站预览显示的卖家 SLS 藏价，按页面证据确定是各 SKU 同一值还是各规格不同。普通买家运费及同一页面的 RM 店铺陈列价分别识别。若页面与模板藏价冲突，以已确认的当前商品实值代入并说明。关键取值缺失时列明，避免用上批参数或自动补零。
3. 依当前公式反推折前价。检查目标利润率分母、折扣、汇率、实际费率和收费基数。使用当前项目公式时参阅 [模板字段与复算方法](references/template.md)。逐 SKU 复算折后价、总成本、利润与成本利润率，确认按 RM0.01 舍入后仍达标。同一 SKU 的模板成本、藏价和折后结果应可追溯。
4. 用户要求填写时，按已核对的规格映射操作可见且可编辑的 RM 店铺售价框。提前核对行数、币种和字段；隐藏输入不计入，可见性和币种用页面证据验证。若主页面用 Playwright，可用 `.filter({visible:true})` 辅助筛选。重绘、分页或匹配差异出现时重取页面状态，逐项核对后再继续。
5. 填后回读全部目标 SKU 及售价，检查界面校验、丢值和误填。仅要求填价时停在「确认发布」之前；仅要求报价时交付计算结果。回复写明取数口径、价格表或同价规格组、核对数量及页面所处状态。
