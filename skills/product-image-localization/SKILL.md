# 商品图英文翻译与验收

1. 枚举实际文件，按主图、详情图和 SKU 图清点。处理 ZIP 时保留相对路径和顺序信息；交付整套英文素材时也纳入无中文字的原图，缺图或 ZIP 不可读时指出具体文件。默认另存并保留原件，用户明确要求覆盖时才覆盖。
2. 读图确认文字和商品事实。英文用自然、简短的商品用语，同一款的颜色、尺寸、件数与 SKU 名称保持对应。缺失单位保留，冲突的数值在交付时标明。按指定范围局部替换文字，保留实物颜色、形状、构图和尺寸标线。仅要求去除某些文字时按指定字段修改。
3. 打开每张最终图片检查全图和文字区域。检查残留中文、拼写、可读性、文字重叠、清除痕迹，以及原图和结果之间的规格与实物一致性。仅要求压缩时优先直接复制已达标图；需压缩的图片优先保留可读文字和清楚的规格线，再检查比例、格式和视觉质量。
4. 翻译后的每张最终图必须严格小于 2,000,000 字节。对最终目录、单图或 ZIP 运行 `python scripts/check_image_sizes.py <交付路径>`。超限先优化再对最终产物重跑。脚本按实际单图或 ZIP 解压后的条目检查字节数，另外验证 ZIP 条目可读性；图片能否正确解码及视觉质量仍逐张检查。
5. 交付路径、处理张数、最大单图字节数，以及需用户核实的商品信息。给 ZIP 时也核对条目名称和数量与交付范围一致。
